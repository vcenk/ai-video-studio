# Visual Language

## Goal

Create modern, clear, high-retention visuals without making every scene look like the same template.

## Hierarchy

Every frame should have an obvious focal point.

Prefer:
- one primary message
- one supporting visual system
- limited simultaneous emphasis

## Typography

Use typography as a visual tool, not merely subtitles.

Good uses:
- large number reveals
- keyword emphasis
- contrast statements
- labels
- chapter transitions
- timelines
- quotes

Avoid filling the frame with paragraphs.

## Motion

Animation should communicate:
- entrance
- exit
- hierarchy
- causality
- comparison
- direction
- transformation

Do not animate everything merely because it can move.

## Charts

Charts should be simplified for video.

Prefer:
- one conclusion per chart
- progressive reveals
- highlighted relevant data
- large labels
- minimal grid noise

## Maps

Use maps when geography matters.

Useful motion:
- route drawing
- location highlighting
- zoom
- region comparison
- distance visualization

## B-roll

Use B-roll when real-world context is useful.

Do not use unrelated stock footage just to avoid an empty frame.

## Screenshots

Screenshots should be cropped and annotated around the exact point being discussed.

Avoid showing an entire webpage when only one small section matters.

## UI demos

Use:
- cursor movement only when meaningful
- callouts
- zoomed areas
- state transitions
- before/after comparisons

## Transitions

Transitions should preferably connect scenes conceptually.

Avoid using a different decorative transition every time.

## Safe areas

For vertical platforms, keep critical text away from:
- extreme top
- extreme bottom
- right-side interaction controls

## Mobile readability

Assume many viewers will watch on a phone.

Text should remain readable at small physical screen size.
