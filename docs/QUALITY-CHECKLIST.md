# Quality Checklist

## Editorial

- [ ] The hook creates immediate interest.
- [ ] The video delivers on the hook.
- [ ] The story has forward momentum.
- [ ] Claims are supported or clearly framed.
- [ ] Repetition has been removed.
- [ ] The ending provides a real payoff.

## Visuals

- [ ] Each scene has a clear focal point.
- [ ] No accidental empty/dead scenes.
- [ ] No text overflow.
- [ ] No important visual is cropped.
- [ ] Text is readable on mobile.
- [ ] B-roll is relevant.
- [ ] Charts communicate one clear conclusion.
- [ ] Screenshots focus on the discussed area.
- [ ] Visual style is reasonably consistent.

## Motion

- [ ] Animation timing feels intentional.
- [ ] No animation depends on unstable wall-clock timing.
- [ ] Transitions do not distract from content.
- [ ] Pattern interrupts are meaningful.
- [ ] Repeated animation patterns have not become monotonous.

## Audio

- [ ] Voice is clear.
- [ ] Music does not overpower narration.
- [ ] SFX are not excessive.
- [ ] Important SFX are synchronized.
- [ ] No clipping or obvious distortion.

## Captions

- [ ] Captions match narration.
- [ ] Caption timing is correct.
- [ ] Caption size is readable.
- [ ] Captions do not collide with platform UI safe zones.

## Assets

- [ ] All referenced assets exist.
- [ ] Final render does not depend on broken remote links.
- [ ] Asset provenance is known where required.
- [ ] No watermarked or obviously unauthorized assets are present.

## Technical

- [ ] Correct aspect ratio.
- [ ] Correct resolution.
- [ ] Correct frame rate.
- [ ] Correct duration.
- [ ] Preview render succeeds.
- [ ] Final render succeeds.
- [ ] Project can be rendered again from repository state.

## Final viewing

Watch the final export:
- once with sound
- once muted

Muted viewing helps identify whether the visual story still makes sense.
