# Captions

## Purpose

Captions improve accessibility, mobile comprehension, and retention.

## Rules

- Keep captions synchronized to spoken delivery.
- Prefer short phrase groups over large sentence blocks.
- Highlight keywords selectively.
- Avoid highlighting every word.
- Keep text within safe areas.
- Use high contrast.
- Ensure captions remain readable over changing backgrounds.

## Short-form

Short-form captions may be more expressive:
- keyword emphasis
- timed scale changes
- per-phrase animation
- selective color changes

Do not let captions compete with the main visual.

## Long-form

Long-form captions should generally be less visually aggressive than Shorts unless the creative direction requires otherwise.
