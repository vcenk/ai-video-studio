# Video Production Workflow

## 1. Brief

Define:
- audience
- platform
- goal
- topic
- target duration
- language
- tone
- required CTA
- brand
- references

## 2. Research

Collect:
- factual claims
- source links
- statistics
- examples
- screenshots
- product references
- dates
- visual references

Keep uncertain claims clearly marked.

## 3. Angle

A topic is not an angle.

Example topic:
- Costco

Possible angle:
- Costco's membership model is more important than most people realize.

The angle should determine what the viewer is meant to understand by the end.

## 4. Hook

The hook must create an information gap, contradiction, surprise, stakes, or immediate utility.

For short-form, the first 1–3 seconds are especially important.

Do not waste the opening on:
- greetings
- logos
- context the viewer does not yet care about
- slow brand intros

## 5. Script

Write for spoken delivery.

Prefer:
- natural sentence length
- rhythm
- contrast
- reveal structure
- clear transitions

Avoid:
- essay-like paragraphs
- unnecessary repetition
- robotic list narration

## 6. Visual script

For each narration block, decide what the viewer should see.

The visual should:
- explain
- prove
- compare
- emphasize
- orient
- entertain
- transition

## 7. Storyboard

Convert the visual script into timed scenes.

Each scene should include:
- start/end time
- narration
- scene purpose
- visual composition
- animation
- on-screen text
- media
- audio cues
- transition

## 8. Asset plan

Classify assets before implementation.

Possible asset classes:
- screenshots
- stock footage
- generated imagery
- generated video
- product UI
- charts
- maps
- icons
- logos
- photos
- screen recordings
- sound effects
- music

## 9. Voice and audio

Establish voice track before fine timing whenever possible.

Animation should follow real narration timing rather than arbitrary guessed timing.

## 10. Build

Implement scenes using shared components whenever practical.

Do not prematurely create generalized abstractions for one-off visuals.

## 11. Captions

Captions should be synchronized, readable, and adapted to the platform.

## 12. Preview

Review:
- pacing
- readability
- dead time
- repetitive composition
- awkward transitions
- audio balance

## 13. Final render

Render at the project-defined target format.

## 14. QC

Use `QUALITY-CHECKLIST.md`.

## 15. Archive

Keep:
- final script
- final storyboard
- asset provenance
- final project config
- final render
